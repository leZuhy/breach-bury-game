# [Breach & Bury]

A third-person survival horror game set in an abandoned asylum, made in Unity.

**[▶ Play on itch.io](https://lezuhy.itch.io/breachbury)**

![Screenshot](screenshot1.png)

## Features
- Grid inventory system (ammo, healing, batteries, keys)
- Flashlight with battery drain that stuns enemies
- Mr. X-style stalker AI with patrol, hunt, search, and sound detection
- Pistol, rifle, and shotgun with full-auto support
- Locked doors with keys or a lockpicking minigame
- Zombies with a state machine AI and loot drops

## Built with
Unity 6, C#, NavMesh, Cinemachine, Git LFS

## Controls
WASD move, RMB aim, LMB shoot, R reload, TAB inventory, E interact
